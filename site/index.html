The parts are guaranteed to sum to total.

From the documentation of ratio_distribute in rich, the Python library that draws tables in your terminal.

ratio_distribute(80, [1, 1, 1], [10, 10, 50])
returns [27, 27, 50]
which adds up to 104, not 80

proob writes down the rules your code promises, then searches for the input that breaks them.

That rule and the input above came from one run. Pointed at the latest releases of six popular Python and Rust libraries, proob found 12 bugs their test suites had missed.

/plugin marketplace add proob-ai/proob
/plugin install proob@proob
/proob:try
Run them in Claude Code, inside your repository. proob works on a private copy, so your files and git status stay as they were.

Bugs it found in libraries you may already use

Each row is a rule proob wrote down for the code, and the input that broke it. Every one was reproduced against the library's latest release in October 2026.

  • attrs

    Any value not in the accepted list raises ValueError.

    converters.to_bool(0.0) returns False.0.0 equals 0, so it slips through the membership test.

  • vaultwarden

    Hiding part of an email address works for any address.

    An address that starts with já makes obscure_email panic.It cuts the string at 2 bytes, not 2 characters. This runs during two-factor login.

  • python-semver

    Two versions that compare equal have the same hash.

    Version(0, 0, 0, "0") and Version(0, 0, 0, "00") compare equal and hash differently.So a set or dict can hold the same version twice.

  • tomlkit

    Reading a document and writing it back gives the original text.

    a=[1979-05-27 ,0] comes back as a=[1979-05-27,0].The space after a date is dropped, though tomlkit promises to keep formatting.

  • rust-url

    Changing part of a URL leaves a URL that reads back the same.

    set_ip_host(0.0.0.0) on foo:// stores an IP address that reads back as a domain name.

  • rich

    Cutting text into cells never loses text.

    chop_cells("\x1f", 1) returns [].Text made only of zero-width characters disappears.

These are 6 of the 12. The full list, with the exact input and a command to replay each one, is in the benchmark.

How we know it wasn't luck

We also took bugs that maintainers had already fixed, rolled each library back to the commit before the fix, and ran proob with no hint that anything was wrong.

What happens when you run it

  1. Try it on a private copy

    /proob:try proposes up to five rules in plain English, writes a check for each, and runs thousands of generated inputs against it. Your repository is not touched.

  2. Keep what your team agrees with

    proob shadow adopt puts the rules and their checks on a new branch. A teammate's pull request review is the approval: the agent only ever proposes.

  3. Let every pull request answer to them

    Make the proob gate check required. A change that breaks an approved rule cannot merge, and new code that no rule covers is pointed out, never blocked.

What it does not do yet

  • Most rules are checked with generated inputs, which sample the space. A rule reads Holds only when a proof (Kani or Verus) or a model check (TLA+) backs it; on a typical project that is the minority today.
  • proob also breaks your code on purpose to see whether each check notices. A check that never notices is reported as unable to fail, not as passing.
  • It supports Python and Rust, and runs inside Claude Code. Python needs pytest, Hypothesis and mutmut; Rust needs cargo-nextest and cargo-mutants. /proob:setup installs what is missing, after asking.
