# Benchmark results: proob v0.1.0

v0.1.0 was released on 2026-10-30 from `0c2fa86`: five platform builds (Linux x86_64 and arm64, macOS x86_64 and arm64, Windows x86_64), each with its SHA-256; the arm64 macOS build was downloaded, checked against its published checksum, and run.

The full measurement was taken on the release candidate, [v0.1.0-rc1](v0.1.0-rc1.md), and stands for this release. The changes between rc1 and v0.1.0 were each verified directly rather than by a new full run:

| Change since rc1 | How it was verified |
|---|---|
| Rust adapter: cargo `features`, `all_features`, `no_default_features`; a declared `[[test]]` replaces the target cargo would infer at its path | The one bug set v2 miss, the `time` crate, now runs: `proob run check` finds the bug (a Sunday-week round trip fails at 0001-01-01) instead of erroring. 464 tests. |
| Parallel mutation jobs sized from the measured build | For vaultwarden (about 2 GB per build copy) the rule now allows 2 jobs at 6.6 GB free, where the old rule allowed 4 and filled the disk. Unit-tested. |
| A missing pytest plugin is named with its fix | python-semver, whose pytest configuration adds `--cov`, now reports the missing plugin and both ways to proceed. Unit-tested. |
| arm64 macOS built on the Intel runner | The released binary is a native arm64 executable and reports `proob 0.1.0`. |

## Headline numbers (from rc1)

| Measure | Result |
|---|---|
| Held-out bugs caught | 18 of 20 trials, 90% (95% interval 70% to 97%) |
| Bugs fixed after the model's training cutoff | 9 of 10, one trial each; the miss is now addressed (above) |
| Wrong `Holds` in 260 scored verdicts | 0 |
| indexmap target trial | 9.4 minutes (was 123) |
| Regression corpus | 84 entries, all reproduce |

## Not yet true

- The repository is private, so the plugin's shim and the Action cannot download this release without a token, release attestations are off, and proob's own gate still builds from source. All three change the day the repository is public.
- vaultwarden's strength scores have not been rerun with the new job sizing.
- No team outside this repository has used proob yet.
